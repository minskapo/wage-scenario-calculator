# 임금인상 시나리오 계산기 — 설계 문서

- 작성일: 2026-07-29
- 목적: 노동조합 임금교섭 준비를 위해 현행 임금·실수령액, 인상 시나리오별 비교, 과거~현재 임금수준 추이, 교섭 참고정보를 한눈에 볼 수 있는 웹 계산기 제작
- 배포: GitHub Pages (정적 사이트)

## 1. 사용 대상 및 사용 맥락

- **집행부/교섭위원**: 소수의 담당자가 조합 대표 사례(직급별)를 입력해 교섭 발표자료·유인물로 활용
- **조합원 개인**: 전체 조합원에게 링크를 공유해 각자 자신의 직급 기준으로 인상 시나리오에 따른 실수령액 변화를 스스로 확인
- 정적 사이트 + 클라이언트 사이드 계산이므로 개인이 입력한 정보는 서버로 전송되지 않고 브라우저 안에서만 처리됨 (백엔드 없음)

## 2. 임금체계 특성 (중요 전제)

- 이 사업장은 **호봉제가 아니며, 직급 5~8개 정도로 구성된 짧은 임금테이블**을 사용함
- 임금테이블·임금협약서·경영지표 등 실제 데이터는 **사용자(조합)가 이후 제공** — 본 설계 문서에는 데이터 스키마만 정의하고, 실제 수치는 구현 단계에서 데이터 파일에 채워 넣음

## 3. 기술 스택 및 아키텍처

**순수 HTML/CSS/JS, 빌드 도구 없음.** 프레임워크·번들러 없이 정적 파일을 그대로 GitHub Pages가 서빙. 배포 실패 지점을 최소화하고, 유지보수(매번 Claude Code에 요청)가 쉬운 구조를 최우선으로 함.

```
/
├── index.html          # 탭 4개(현황·시나리오·추이·참고정보) 단일 페이지 앱
├── css/
│   └── style.css       # 흑백 베이스 + 포인트 그린 rgb(0,188,112)
├── js/
│   ├── data/
│   │   ├── wage-table.js       # 직급별 임금테이블 (기본급 + 수당 항목)
│   │   ├── tax-rules.js        # 4대보험 요율, 소득세 계산 상수 (연도별)
│   │   └── reference-data.js   # 최저임금 인상률, 물가상승률, 산업평균 인상률, 경영지표 이력, 조합 자체 인상률 이력
│   ├── calc/
│   │   ├── net-pay.js          # 실수령액 계산 (4대보험 + 소득세)
│   │   └── scenario.js         # 인상 시나리오 적용 로직
│   ├── charts/
│   │   └── trend-chart.js      # 추이 그래프 렌더링 (경량, 외부 의존 최소화)
│   ├── export/
│   │   └── image-export.js     # 표/카드 이미지 다운로드
│   └── main.js                 # 탭 전환, 상태 관리, 렌더링 조립
```

데이터와 계산/렌더링 로직을 분리해 연도가 바뀌거나(최저임금 갱신 등) 새 임금협약이 체결됐을 때 데이터 파일만 교체하면 되도록 함.

## 5. 페이지 구조

탭 기반 단일 페이지 앱. 상단 고정 탭: **[현황] [시나리오] [추이] [참고정보]**. 탭 전환 시 URL 새로고침 없이 해당 섹션만 표시.

## 6. 탭별 기능

### ① 현황 탭
- 전체 직급별 임금테이블(기본급·각 수당 항목·총액)과 각 직급의 실수령액(4대보험/소득세 공제 내역 포함)을 표로 전부 표시
- 사용자가 자신의 직급을 선택하면 해당 행이 하이라이트되고, 상단에 본인 기준 요약 카드(총 임금 / 공제액 / 실수령액) 표시

### ② 시나리오 탭
- **시나리오 빌더**: 시나리오를 여러 개 추가/삭제/복제 가능. 각 시나리오는:
  - 이름 지정 (예: "조합안", "사측안", "자체 검토안")
  - 임금 항목별로 정률(%) 또는 정액(원) 인상 방식을 개별 지정 가능
  - 새 임금 항목(신설 수당 등) 추가 가능
- 설정한 인상률/인상액은 **전체 직급표에 동일하게 일괄 적용**되어, 시나리오별 전체 직급표 결과를 나란히 비교
- 현황 탭에서 선택(강조)된 직급을 기준으로, 시나리오별 "인상 전 → 인상 후" 임금총액·실수령액·인상폭(금액/비율) 요약 비교 카드를 상단에 별도 표시

### ③ 추이 탭
- 조합 자체의 연도별 임금인상률·인상방식(정률/정액/혼합) 이력을 라인/바 차트로 표시
- 연도 클릭 시 해당 연도 인상 방식에 대한 간단한 설명 툴팁

### ④ 참고정보 탭
- 역대 최저임금 인상률 추이
- 소비자물가상승률(물가인상률) 추이
- 동종/전산업 평균 임금인상률 통계
- 기업 경영지표(영업이익·당기순이익 등) 추이 — 사용자가 직접 수치 입력해 관리
- 위 항목들과 조합 자체 인상률을 겹쳐 비교할 수 있는 차트 1개 포함 (예: "우리 인상률이 물가상승률에도 못 미친다"는 근거 자료로 바로 활용)

## 7. 실수령액 계산 로직

1. **4대보험료 공제**: 국민연금, 건강보험, 장기요양보험, 고용보험 — 요율은 `tax-rules.js`에 상수로 분리, 구현 시 2026년 기준 최신 요율 확인 후 반영
2. **소득세 공제**: 국세청 근로소득 간이세액표는 수만 행짜리 조견표라 통째로 내장하지 않고, 간이세액표 산출 계산식(연간환산 → 근로소득공제 → 인적공제 → 종합소득세율표 적용 → 12분의1 환산 → 근로소득세액공제)을 그대로 구현. 지방소득세(소득세의 10%)도 함께 계산
3. **인적공제 입력**: 부양가족 수(본인 포함), 20세 이하 자녀 수 등을 간단한 입력 필드로 받되 기본값(본인 1인)으로 즉시 계산 가능하게 함
4. 화면에 "간이 추정치이며 실제 명세서와 차이가 있을 수 있음" 안내 문구 명시
5. 구현 단계에서 실제 간이세액표 조견표 샘플 값과 대조해 오차 검증

### 시나리오 적용 파이프라인
- `scenario.js`가 각 직급의 임금 항목(배열 구조 `{name, amount, taxable}`)에 정률/정액 인상을 적용해 새 임금총액 산출 → `net-pay.js`로 그대로 전달해 실수령액 재계산
- 신설 항목 추가도 동일 파이프라인을 타도록 임금 항목을 고정 필드가 아닌 배열로 설계 (4번 참고)

## 8. 디자인 시스템

- **베이스**: 흑백·그레이 톤, 라이트 모드 우선 구현
- **포인트 컬러**: 그린 `rgb(0, 188, 112)` — 강조 버튼, 활성 탭, 본인 행 하이라이트, 인상분 표시 등에 사용
- 특정 조합 로고/브랜딩 없이 신뢰감 있는 중립적 일반 디자인
- 카드형 레이아웃, 표는 가로 스크롤 대응(모바일 고려)

## 9. 내보내기

- 각 표/카드 영역에 "이미지로 저장" 버튼 제공 → PNG 다운로드
- 자체 canvas 렌더링을 우선 검토하고, 구현 난이도가 높으면 검증된 경량 캡처 라이브러리 1개(CDN)를 예외적으로 허용

## 10. 배포

- GitHub Pages: 리포지토리 루트를 Pages 소스로 지정, 빌드 단계 없이 정적 파일 그대로 서빙
- 커스텀 도메인 없이 기본 `*.github.io` 경로 사용

## 11. 테스트 전략

- 별도 유닛테스트 프레임워크 없이, 계산 로직(`calc/*.js`)에 대한 브라우저 콘솔 실행형 스모크 테스트 스크립트 작성 (샘플 직급 + 알려진 간이세액표 값과 대조)
- 로컬에서 정적 서버로 띄워 수동 확인

## 12. 구현 단계에서 확정해야 할 항목 (Open Items)

- 실제 직급별 임금테이블·임금협약서 이력 데이터 (사용자 제공 예정)
- 2026년 기준 4대보험 요율 최신값
- 최저임금 이력, 소비자물가상승률 이력, 동종/전산업 평균 임금인상률 통계 (공신력 있는 출처 확인 후 반영)
- 기업 경영지표 수치 (사용자 직접 입력)
